線上靈堂專案說明

這個 GitHub Pages 只能放靜態說明頁。完整的會員、靈堂、時光膠囊系統是 Node.js 網站，需要在伺服器上啟動，無法直接靠 GitHub Pages 運作。

為什麼會看到 404？

GitHub Pages 不會執行 node src/server.js，也不支援 SQLite、登入與上傳。倉庫裡原本沒有首頁 HTML，所以網址會顯示找不到檔案。

本機啟動

  1. 安裝 Node.js
  2. 在專案資料夾執行 npm install
  3. 再執行 npm start
  4. 開啟 http://127.0.0.1:3000

若要給別人線上使用

需要部署到支援 Node.js 的主機，例如 Railway、Render、Fly.io 或自有 VPS。需要的話可以再幫你接上線部署。
